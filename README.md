# Lumé — сайт клиники эстетической косметологии

Готовый fullstack-сайт на **Next.js 16 + React 19 + Tailwind CSS 4**: лендинг, каталог услуг с ценами, онлайн-запись с выбором специалиста и свободного времени, отзывы с модерацией и админ-панель.

- Локально запускается без настройки базы: заявки сохраняются в `.data/db.json`.
- В продакшене подключается **PostgreSQL** одной переменной `DATABASE_URL` (Neon, Supabase, Render) — таблицы создаются автоматически.

## Что внутри

| Раздел | Что умеет |
| --- | --- |
| Главная `/` | Подбор процедуры по запросу («Морщины», «Пигментация»…), преимущества, популярные услуги, о клинике, специалисты, отзывы, контакты с картой и статусом «Открыто до 21:00» |
| Услуги `/services` | Фильтр по категориям (инъекции, аппаратная, уход, лазер), поиск, модальное окно с эффектом, показаниями и противопоказаниями. У каждой услуги есть своя страница `/services/[slug]` для SEO |
| Запись `/booking` | 4 шага: услуга → специалист (или «любой») → дата и свободное время → контакты. Валидация на клиенте и сервере, защита от двойной записи на одно время, файл .ics «Добавить в календарь» |
| Админка `/admin` | Вход по паролю. Заявки: фильтры по периоду и статусу, поиск, смена статуса, удаление, экспорт в CSV. Отзывы: публикация, скрытие, удаление |
| API | `/api/availability`, `/api/bookings`, `/api/reviews`, `/api/admin/*`, `/api/health` |

Дополнительно: уведомления о новых заявках в Telegram, защита от спама (скрытое поле и ограничение частоты), robots.txt, sitemap.xml, разметка Schema.org, адаптивная вёрстка, доступность с клавиатуры, учёт `prefers-reduced-motion`.

## Запуск за 2 минуты

Нужен **Node.js 20.9 или новее** (рекомендуется 22 LTS): https://nodejs.org

1. Распакуйте архив и откройте папку в терминале:
   ```bash
   cd lume-clinic
   ```
   Или клонируйте репозиторий: `git clone <адрес-репозитория> && cd lume-clinic`.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите в режиме разработки:
   ```bash
   npm run dev
   ```
4. Откройте http://localhost:3000. Админка — http://localhost:3000/admin, пароль в режиме разработки: `admin`.

Свой пароль и другие настройки — в файле `.env.local` (скопируйте из `.env.example`):

```bash
cp .env.example .env.local
```

Продакшен-сборка локально:

```bash
npm run build
ADMIN_PASSWORD=ваш-пароль npm start
```

## Переменные окружения

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `ADMIN_PASSWORD` | в продакшене | Пароль админ-панели. Без него вход в продакшене отключён |
| `DATABASE_URL` | в продакшене | Строка подключения PostgreSQL. Без неё данные пишутся в JSON-файл |
| `SESSION_SECRET` | нет | Секрет подписи сессий (по умолчанию выводится из пароля) |
| `NEXT_PUBLIC_SITE_URL` | нет | Адрес сайта для SEO. На Vercel и Render определяется сам |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | нет | Уведомления о новых записях в Telegram |
| `DATA_DIR` | нет | Папка JSON-хранилища (по умолчанию `.data`) |

## Деплой бесплатно

> На Vercel и бесплатном Render файловая система временная, поэтому для продакшена обязательно подключите PostgreSQL. Без базы сайт работает, но заявки пропадут при перезапуске — админка покажет об этом предупреждение.

### Вариант 1. Vercel + Neon (рекомендуется)

1. Загрузите проект на GitHub:
   ```bash
   git init && git add . && git commit -m "Lumé"
   git branch -M main
   git remote add origin https://github.com/<вы>/lume-clinic.git
   git push -u origin main
   ```
2. Зайдите на https://vercel.com → **Add New → Project** → импортируйте репозиторий. Настройки сборки Vercel определит сам (Next.js). Нажмите **Deploy**.
3. Подключите базу: в проекте откройте **Storage → Create Database → Neon (Serverless Postgres)** → бесплатный тариф → **Connect** к проекту. Vercel сам добавит переменную `DATABASE_URL`.
4. **Settings → Environment Variables**: добавьте `ADMIN_PASSWORD` (и при желании `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`).
5. **Deployments → … → Redeploy**, чтобы переменные применились. Готово: сайт доступен по адресу вида `https://lume-clinic.vercel.app`.

Без GitHub можно задеплоить прямо из папки: `npx vercel` (затем `npx vercel --prod`), а переменные добавить в панели Vercel.

### Вариант 2. Render (сайт и база в одном месте)

1. Загрузите проект на GitHub (шаг 1 выше).
2. Зайдите на https://render.com → **New → Blueprint** → выберите репозиторий. Render прочитает `render.yaml` и создаст веб-сервис и бесплатную базу PostgreSQL.
3. Введите `ADMIN_PASSWORD`, когда Render его попросит, и нажмите **Apply**. Через несколько минут сайт будет доступен по адресу вида `https://lume-clinic.onrender.com`.

Особенности бесплатного тарифа Render: сервис засыпает через 15 минут без посещений и просыпается около минуты; бесплатная база удаляется через 30 дней (плюс 14 дней на продление). Для постоянной работы бесплатно возьмите базу в Neon (https://neon.tech) и укажите её строку подключения в `DATABASE_URL` вместо базы Render.

### Свой сервер (VPS)

```bash
npm install && npm run build
DATABASE_URL=... ADMIN_PASSWORD=... npm start   # порт задаётся переменной PORT, по умолчанию 3000
```

## Как настроить под свою клинику

| Что изменить | Где |
| --- | --- |
| Название, телефон, адрес, мессенджеры, часы работы, часовой пояс, валюта, лицензия, координаты карты | `src/config/site.ts` |
| Услуги, цены, длительность, описания, блок «Что хотите изменить?» | `src/data/services.ts` |
| Специалисты, их направления и дни приёма | `src/data/specialists.ts` |
| Фотографии | положите файлы в `public/images` и укажите пути в `src/config/site.ts` → `images` |
| Цвета и шрифты | `tailwind.config.js`, шрифты — `src/app/layout.tsx` |
| Текст политики обработки данных | `src/app/(site)/privacy/page.tsx` (согласуйте с юристом) |

Имена специалистов, адрес, телефон и реквизиты в проекте — образцы: замените их на реальные данные перед запуском. Отзывы на сайте только настоящие: пациенты оставляют их через форму, а вы публикуете их в админке.

Длительность услуги определяет сетку записи: свободное время считается по рабочим дням специалиста, часам работы клиники и уже занятым интервалам. На сегодня запись открыта не ранее чем через час (настраивается в `booking.minLeadMinutes`).

### Уведомления в Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Напишите боту любое сообщение (или добавьте его в рабочую группу).
3. Узнайте `chat_id`: откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}`.
4. Добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в переменные окружения.

## API

| Метод и путь | Описание |
| --- | --- |
| `GET /api/availability?service=slug&specialist=id\|any&date=YYYY-MM-DD` | Свободное время на дату |
| `POST /api/bookings` | Создать запись `{ serviceSlug, specialistId, date, time, name, phone, comment?, consent }` |
| `GET /api/reviews` / `POST /api/reviews` | Опубликованные отзывы / новый отзыв (уходит на модерацию) |
| `POST /api/admin/login`, `POST /api/admin/logout` | Вход и выход |
| `GET /api/admin/bookings`, `PATCH/DELETE /api/admin/bookings/:id` | Заявки: список, статус, удаление |
| `GET /api/admin/reviews`, `PATCH/DELETE /api/admin/reviews/:id` | Отзывы: список, публикация, удаление |
| `GET /api/health` | Проверка работы сайта и базы |

Статусы заявок: `new` (новая), `confirmed` (подтверждена), `completed` (завершена), `cancelled` (отменена — освобождает время).

## Безопасность

- Пароль админки сравнивается за постоянное время, сессия — подписанная HMAC httpOnly-cookie на 7 дней; смена пароля завершает все сессии.
- Изменяющие запросы админки проверяют Origin (защита от CSRF), вход ограничен 10 попытками за 15 минут.
- Формы записи и отзывов: валидация zod на сервере, скрытое поле от ботов, ограничение частоты по IP.
- Двойная запись на одно время исключена: в PostgreSQL — транзакция с advisory-блокировкой на дату, в JSON — очередь записи.
